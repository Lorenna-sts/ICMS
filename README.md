# ICMS
Processamento de Arrecadação ICMS 2024
Este script Python automatiza a consolidação de dados de arrecadação do ICMS por município e categoria econômica, realizando o cruzamento entre dados brutos (extraídos do OneDrive) e uma estrutura padrão de banco de dados (armazenada em rede).🚀 FuncionalidadesNormalização de Dados: Tratamento de nomes de municípios para evitar erros com acentos ou variações de maiúsculas/minúsculas.Limpeza Numérica: Conversão automática de formatos de moeda brasileiros (vírgula como decimal e ponto como milhar) para tipos numéricos processáveis.Mapeamento de Categorias: Tradução das categorias econômicas (GM_ALT) para códigos numéricos específicos (446 a 455).Cálculo de Totais: Geração automática do valor total de arrecadação por município (Código 330).Conversão de Unidade: Transformação dos valores brutos para R$ mil reais.Formatação de Saída: Geração de arquivo CSV com formatação visual brasileira (1.234,56) compatível com Excel.📊 Mapeamento de VariáveisO script organiza os dados seguindo a tabela de códigos abaixo:Categoria EconômicaCódigo da VariávelComércio Atacadista e Distribuidor446Comércio Varejista447Extrator Mineral ou Fóssil448Indústria449Prestação de Serviço450Produção Agropecuária451Combustível452Comunicação453Energia Elétrica454Outros455Total Arrecadação ICMS330🛠️ Pré-requisitosPara executar este script, você precisará de:Python 3.10 ou superior.Biblioteca pandas instalada.Acesso aos diretórios de rede (Unidade Z: mapeada).Bashpip install pandas
📂 Estrutura de ArquivosEntrada 1: C:\Users\...\ICMS 2024.csv (Dados brutos de origem).Entrada 2: \\arquivosimb01\...\Arrecadacao ICMS 2024_.csv (Template/Estrutura de destino).Saída: Z:\GEDE\BDE - Banco de Dados\2025\ipva_itcd_icms\Arrecadacao_ICMS_2024_Formatado.csv.⚙️ Lógica de ProcessamentoLeitura: O script lê os CSVs detectando automaticamente se o separador é vírgula ou ponto-e-vírgula.Tratamento: Os valores monetários são limpos e convertidos em float. Os nomes dos municípios passam por uma função que remove acentos para garantir o "match" entre as tabelas.Agrupamento: É feita a soma dos valores por município e por categoria.Cálculo Total: Uma soma extra é feita ignorando as categorias para gerar o código 330 (Soma Total).Merge: Os dados calculados são inseridos no template que contém todos os municípios do estado.Formatação: O número final é transformado em texto com separador de milhar . e decimal , para visualização executiva.📝 Notas de Versãov1.0: Versão inicial com mapeamento de códigos e cálculo de totais.v1.1: Correção de erro de tipos (TypeError) e adição de normalização Unicode.v1.2: Implementação de formatação de saída padrão brasileiro e integração com diretório de rede Z:.Desenvolvido por: Lorenna Santos / GEDEÚltima Atualização: 2025
